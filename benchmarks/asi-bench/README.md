# BenchFlow x Asi Bench

Scaffold generated by `bench eval adopt asi-bench --scaffold-only`. Convert the
upstream **Asi Bench** benchmark into BenchFlow (Harbor-format) tasks.

## Files

- `benchflow.py` — converter (documented `convert()` / `convert_all()` entry points)
- `main.py` — converter CLI delegator
- `parity_test.py` — structural / eval / side-by-side parity checks
- `parity_experiment.json` — recorded per-criterion + reward-distribution parity
- `benchmark.yaml` — standard descriptor
- `run_asi-bench.py` — runner (convert, then evaluate via BenchFlow)
- `asi-bench.yaml` — job config

## Workflow

1. Implement `convert()` (see `benchmarks/programbench/` for a worked example).
2. `python benchmarks/asi-bench/parity_test.py --mode full`
3. Record per-criterion verdicts in `parity_experiment.json`.
4. `bench eval adopt asi-bench --verify` — confirm parity before opening a PR.

Parity is the only gate: the conversion must reproduce the original's behavior
on identical inputs, never "improve" or sanitize it.
